# 圆筒包装接缝避让

输入筒体周长、接缝安全宽度与若干毫米制印刷保护区，系统按周长归一化跨零点区间、合并禁用旋转范围、列出全部可行角度段，并默认选择距禁用边界最远、角度最小的旋转量。Canvas 同步预览接缝与保护区，拖动时吸附到最近可行位置；无解时展示覆盖整圈的禁用区间链。

## 设备档位约束

在参数面板勾选「启用设备档位约束」（单规格与多规格共用此设置，可分别填写 **每圈档位数 2～360 的整数** 与 **零位偏移 (°)**）：

- 系统只允许角度 `θ = 偏移 + n × 360°/档位数`（按整圈归一到 0°–360°），偏移超出范围自动按整圈归一。
- 档位与当前**可行段**（单规格）或**共用段**（多规格）求交（边界档位也算可用），默认档位沿用 **「瓶颈间隙最大、角度较小优先」** 规则；右栏列出**全部可用档位**及间隙（单规格为该档到最近禁用边界的角距离；多规格逐规格列出间隙与瓶颈档）。
- **连续区间有解但没有可用档位**时，与「保护区覆盖整圈」明确区分：结果区给出琥珀色提示，按每条可行/共用段列出**距该段最近的前、后档位**及角距离；Canvas 环外灰色短刻度为全部档位，琥珀色菱形为最近档位。
- Canvas 拖动**只吸附到可用档位**（圆周距离最近，并列取较小角度），点击可行段则选中该段内的默认可用档位；没有可用档位时位置线变琥珀色且不移动。
- **关闭约束后行为与此前完全一致**；勾选状态、档位数与偏移在单/多规格模式切换、计算与载入快照时都**保留在表单中**，不会因切换模式丢失。

## 多规格共用角度模式

顶部切换到「多规格共用角度」后，可输入 **2～8 个筒体周长**，沿用同一接缝安全宽度与同一组毫米制保护区：

- 系统对每个规格分别计算，再把各规格可行段统一到角度域 **0°–360°** 求圆周交集，输出**所有规格均安全的共用角度段**（跨零点自动合并展示）。
- **默认共用角度**：对候选角度 θ 取其在各规格下到禁用边界的圆周角距离的最小值并最大化（即瓶颈间隙最大），平局时取较小角度；右栏列出该角度在每个规格下的实际间隙与对应毫米位置。
- **无共同解**时，按规格输入顺序定位使公共交集**首次归零**的规格，列出该规格及其禁用区间与此前公共段的**冲突区间**，Canvas 上以红虚线标出。
- **最小违约备选**：公共可行段为空时（无共同解），系统进一步给出一个"违约最小"的备选角度——按各规格禁用角度边界切分整圆，角度落在某规格禁用区内时记其**侵入深度**（沿圆周走出该禁用区所需的最小角距离），选取使**所有规格中最大侵入深度最小**的角度；并列时依次比较**总侵入深度**与**较小角度**。结果区显示备选角度、最大/总侵入深度与各规格侵入深度及无解原因，Canvas 以**琥珀色位置线与菱形**标记该角度（仅作参考，不能变为安全角度）。**启用设备档位约束时只在档位角度中求解**，对应档位刻度同样以琥珀色标出。存在共同安全段时不进行该计算，结果与此前完全一致。
- Canvas 由外向内**叠加每个规格的禁用环**（颜色对应规格序号），绿色环为共用安全段；拖动时吸附到最近的共用安全角度。
- 切回「单规格模式」时，单规格的周长与多规格周长列表均保留在页面中，**不会丢失任何已输入内容**。
- 方案快照仅保存单规格结果，多规格模式下快照入口自动禁用。

## 调机旋转路径规划

在结果区旁的「调机旋转路径」面板输入**当前角度**与**目标角度**（°，任意数值，按整圈归一），系统基于当前计算结果的**可行段**（单规格）或**共用安全段**（多规格）规划调机路径：

- 只允许沿圆周**单向连续旋转**且**全过程处于安全角度**（可行/共用段内，含边界）；分别评估顺时针与逆时针两条路径，均可达时选**转角较短**者，**等长（含起终点相同）取顺时针**。
- **启用设备档位约束时，两端还必须落在可用档位上**（调机只停靠在档位，中间连续旋转不受档位限制）。
- 跨 0°、整圈可行、起终点相同（转角 0°）均正确处理；两端各自安全但被禁用段隔开时报告**不可达**；端点不在安全段内、不在可用档位上时**分别指出**。
- 页面显示**方向**与**转角**，并在 Canvas 上以紫色路径弧（带箭头，叠在可行/共用环上）标出，from 空心点、to 实心点；不可达时端点标红。任何参数重算后路径结果**同步刷新**。

## 安装误差分析

在参数面板勾选「启用安装误差分析」（单/多规格共用此设置），分别填写**逆时针误差 (°)** 与**顺时针误差 (°)**（均为非负有限角度）：

- 标称角度 θ 存在安装误差时，实际角度可能落在从 **θ−逆时针误差** 到 **θ+顺时针误差** 的整条正向圆弧（宽 = 两侧误差之和）上的任意位置。**θ 可靠 ⟺ 该圆弧整条落在安全段内**（单规格取可行段、多规格取共用安全段，含边界）。
- 结果区独立展示**全部可靠角度段**：每条宽 w 的安全弧收缩为宽 w−误差总宽 的可靠段；**跨零点、整圈安全**均正确处理；安全弧宽恰好等于误差总宽时**收缩后仅剩一个点**（仍可靠，单独标出）；**误差总宽达到 360° 时误差弧覆盖整圈，仅整圈安全有解**，否则可靠段为空。
- **启用设备档位约束时**，列出**落在可靠段内的全部档位**（含边界与单点命中），并明确区分**可靠段为空**与**有可靠段但无档位**两种情形。
- Canvas 在可行/共用环上以**青色窄环叠加可靠段**（单点段画圆点），结果区同步列出可靠段与可靠档位；任何参数变化（含误差本身）都**同步刷新**。
- 未启用误差分析时，请求不带 `tolerance`，**接口响应与此前完全一致**（无 `tolerance` 字段）。

## 方案快照

- 在「方案快照」面板可为**当前周长、接缝宽度、保护区、设备档位与安装误差设置的计算结果**命名并保存；快照按时间倒序列出，支持载入参数（含档位开关、档位数与偏移、两侧安装误差）与删除。
- 勾选两个快照（依次标记为 A、B）后点击比较：系统将三类圆周区间（保护区、合并禁用段、可行段）统一归一化到 **0°–360°**，即使两个快照周长不同也可比较。
- 差异输出：
  - **新增**（B 有 A 无，绿色）／**移除**（A 有 B 无，红色）的圆周区间；
  - **边界移动**（紫色）：按重叠最大配对对应段，给出起点/终点沿最短圆弧的有向位移（顺时针 +、逆时针 −），跨零点自动取短弧；
  - 共有的部分以灰色底环显示。
- 差异 Canvas 上三个环分别对应可行段（外）、禁用段（中）、保护区（内），右栏列出逐段明细（角度，并附各快照周长下的毫米参考值）。
- 快照数据保存在浏览器 **localStorage**（键 `seam-avoidance:snapshots:v1`，最多 100 个），不经过服务器；清除浏览器数据即删除。重新计算或「返回实时预览」即回到原有实时预览。

## 启动（Docker）

前置条件：已安装 Docker 与 Docker Compose（Docker Desktop 自带 `docker compose` 插件）。

单条启动命令（在项目根目录，含 `docker-compose.yml`）：

```bash
docker compose up --build
```

首次启动会执行 `npm ci --omit=dev` 安装依赖并纳入镜像，启动即就绪；修改 `server.js`、`src/` 或 `public/` 后需重新 `docker compose up --build`。镜像基于 `node:20-alpine`，容器内以 `node server.js` 运行，不包含开发依赖与单元测试（测试见下方本地开发）。

```bash
# 后台运行 / 查看日志 / 停止
docker compose up --build -d
docker compose logs -f
docker compose down
```

## 访问

- 网页：http://localhost:3000
- API：与网页同端口，路径前缀 `/api`（如 `POST http://localhost:3000/api/compute`，健康检查 `GET http://localhost:3000/api/health`）

## API

| 方法 & 路径 | 说明 |
| ----------- | ---- |
| `POST /api/compute` | 单规格计算。请求体：`{circumference, seamWidth, zones:[{start,end}], detents?, route?, tolerance?}`（单位 mm） |
| `POST /api/compute-multi` | 多规格共用角度。请求体：`{circumferences:[…2～8 个周长…], seamWidth, zones, detents?, route?, tolerance?}`；返回每个规格的完整单规格结果（`specs[].result`）、圆周交集 `common`（角度弧段）、默认角度 `best.deg` 及各规格间隙 `best.gaps`；无共同解时 `noSolution=true` 并给出 `blocker`（首次归零的规格序号、此前公共段 `priorCommon`、该规格禁用段 `blockingForbidden` 与冲突区间 `conflictSegments`）与最小违约备选 `fallback`（见下） |
| `GET /api/health` | 健康检查 |

`detents`（可选）为设备档位约束：`{enabled:true, steps:2～360 的整数, offsetDeg?:数值角度}`；缺省或 `enabled:false` 时行为不变（返回 `detents:{enabled:false}`）。启用后返回：

### 圆周区间表示约定（0°/360° 统一）

单规格 `feasible[]` 与多规格 `common[]` 的弧段采用同一套表示：

- 普通不跨零弧：`{startDeg, endDeg, wraps:false}`，`0 ≤ startDeg ≤ endDeg ≤ 360`。弧段**恰好结束在整圈边界**时末端写作 `360`（不模回 `0`），如安全段 90°→360°；恰从零点开始时起点写作 `0` 且不标记跨零。
- 真正跨零弧：`{startDeg, endDeg, wraps:true}`，从 `startDeg` 沿正向越过 0° 到 `endDeg`，宽度由 `widthDeg` 给出。
- 整圈可行：`{full:true, startDeg:0, endDeg:0, widthDeg:360}`。
- `0°` 与 `360°` 为同一圆周点，均按弧端点处理（含边界）。单规格与多规格接口在可行段、可用档位、默认角度与调机路径上的判定保持一致。

启用档位后返回：

- `detents.steps / offsetDeg / stepDeg / positions`：档位参数与全部档位角度；
- `detents.available`：全部可用档位。单规格每项 `{index, deg, mm, gapDeg}`；多规格每项 `{index, deg, minGapDeg, gaps:[各规格间隙]}`；
- 单规格 `best` 取最优可用档位（附 `detentIndex`）；多规格 `best` 同理；
- 连续区间有解但无可用档位时 `best=null`、`detents.noAvailable=true`，`detents.nearest[]` 按可行/共用弧给出 `{before, after}`（最近前、后档位及角距离）；保护区覆盖整圈时 `noSolution=true`、`noAvailable=false`。

### 调机旋转路径 `route`（两个计算接口均可选）

请求体带 `route:{fromDeg, toDeg}`（角度，任意数值，按整圈归一）时，返回中增加 `route` 字段；缺省为 `null`。单规格基于**可行段**、多规格基于**共用安全段**判断，两个接口返回结构一致：

| 字段 | 说明 |
| ---- | ---- |
| `fromDeg` / `toDeg` | 归一化到 0°–360° 的当前/目标角度 |
| `samePoint` | 归一化后起终点是否相同 |
| `detentsConstrained` | 是否启用了档位约束（启用时两端须落在可用档位上） |
| `from` / `to` | 端点判定 `{safe, onDetent, detentIndex}`：`safe` 是否落在安全段内；`onDetent` 是否在可用档位上（未启用档位为 `null`）；`detentIndex` 命中的档位序号（0 起，未命中为 `null`） |
| `status` | `ok` 可达 ｜ `unreachable` 两端各自安全但被禁用段隔开 ｜ `unsafe-endpoint` 端点不在安全段内 ｜ `off-detent` 端点不在可用档位上 |
| `reason` | 人类可读结论/原因文本（端点问题分别指出） |
| `cw` / `ccw` | 顺时针/逆时针路径 `{sweepDeg, reachable}`：扫掠角与是否可达（全程安全） |
| `best` | 所选路径 `{direction:'cw'/'ccw', directionLabel, sweepDeg, fromDeg, toDeg}`；可达方向中取转角较短者，等长（含起终点相同的 0°）取顺时针；不可达时为 `null` |

`route` 参数非法（非对象、`fromDeg`/`toDeg` 非数值）时接口返回 400。

### 安装误差分析 `tolerance`（两个计算接口均可选）

请求体带 `tolerance:{ccwDeg, cwDeg}`（逆时针/顺时针误差，均为**非负有限角度**，单位 °）时，返回中增加 `tolerance` 字段；**缺省时响应不含该字段，与此前完全一致**。`tolerance` 参数非法（非对象、缺失、负数、非有限数）时接口返回 400。

判定规则：标称角度 θ **可靠** ⟺ 从 θ−ccwDeg 到 θ+cwDeg 的整条正向圆弧（宽 = ccwDeg+cwDeg）均落在安全段内（单规格取可行段、多规格取共用安全段，含边界）。返回字段：

| 字段 | 说明 |
| ---- | ---- |
| `ccwDeg` / `cwDeg` / `totalDeg` | 两侧误差与误差总宽（°） |
| `arcs[]` | 全部可靠角度段，表示约定与可行段/共用段一致（单规格附 `startMm/endMm/widthMm`）；安全弧宽恰好等于误差总宽时输出**单点段** `{startDeg=endDeg, widthDeg:0, point:true}`；整圈安全输出 `{full:true, widthDeg:360}` |
| `full` / `empty` | 可靠段是否覆盖整圈 / 是否为空。误差总宽 ≥ 360° 时误差弧覆盖整圈，仅整圈安全有解，否则 `empty=true` |
| `detents` | 启用档位约束时为 `{available, noAvailable}`：`available` 为落在可靠段内（含边界/单点）的全部档位（结构与 `detents.available` 一致）；`noAvailable=true` 表示**有可靠段但无档位**（与 `empty=true` 的**可靠段为空**区分）。未启用档位为 `null` |

### 最小违约备选 `fallback`（仅 `POST /api/compute-multi`）

公共可行段为空（`noSolution=true`）时返回；有共同安全段时为 `null`。字段：

| 字段 | 说明 |
| ---- | ---- |
| `deg` | 备选角度（°）：使各规格**最大侵入深度最小**，并列比**总侵入深度**，再并列取**较小角度** |
| `maxIntrusionDeg` | 该角度下各规格侵入深度的最大值（°），为 0 表示存在不侵入任何规格禁用区的角度（公共段仅在零宽边界点相接） |
| `totalIntrusionDeg` | 各规格侵入深度之和（°），最大深度并列时的比较依据 |
| `intrusions[]` | 逐规格明细 `{index, circumference, intrusionDeg, mm}`；`intrusionDeg=0` 表示该规格在此角度安全，整圈禁用的规格恒为 180° |
| `detentIndex` | 启用档位约束时备选角度对应的档位序号（0 起）；未启用为 `null` |
| `positions` | 启用档位约束时参与求解的全部档位角度；未启用为 `null`（求解域仅限档位角度） |
| `reason` | 无解原因说明文本（含首次归零规格、是否整圈禁用、求解域是否限定在档位） |

侵入深度定义：角度 θ 落在某规格禁用弧内时，沿圆周走到该弧最近出口的角距离；落在安全处为 0。
